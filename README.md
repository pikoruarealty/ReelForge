# ReelForge 3.0 — Motion Graphics Edition

**Default video style is now modern motion graphics instead of still photos with zooms.**
The new Remotion template contains kinetic large text, animated counters, numbered step cards, before/after comparison cards, animated progress graphics, stylized caption overlays, accent gradients and a closing call-to-action.

## Upgrade notes (important)

- Set `RENDER_STYLE=motion_graphics`, `USE_REMOTION=true` and `MOTION_ENABLED=false` in `.env`. AI video motion is **not required** for these animations.
- Set `GRAPHICS_IMAGE_SCENES=2,4` to pay for only two photographic background assets per six-scene Reel in live mode. Decorative SVG assets are created locally for the other four scenes.
- The graphics are animated with Remotion; if rendering fails, a real error is shown instead of silently returning the old FFmpeg slideshow.
- `RENDER_STYLE=cinematic` restores the original image-based presentation with optional Seedance video clips.
- The six layouts currently follow a fixed template order: hook, animated count, step list, before/after, progress animation and CTA. They are design examples, not an AI-selected visual format for each statement. The animated progress and comparison copy are **illustrative design graphics, not factual measurements**.
- Scene timing still comes from the existing six-scene storyboard, so the video is not yet truly audio-aligned unless Whisper is configured.
- No dependencies or API keys have changed. Preserve your existing `.env` and storage when applying the patch.

## Main demo commands

```bash
cp .env.example .env
npm install
npm run dev
```

Open http://127.0.0.1:5173 and generate a new Reel (existing videos are not retroactively re-rendered).

# ReelForge 2.0 — OpenRouter + Hybrid Motion Demo

A **local-first video generation demo** for the requested OpenRouter Claude + OpenRouter image generation + ElevenLabs/Kokoro + Remotion/FFmpeg stack. The UI generates a 30-second portrait MP4 using a structured six-scene storyboard. Includes demo and paid live modes, progress tracking, scene evaluation, bounded revisions, and downloadable outputs.

> This is a **video-generation demo**, not the complete social-media platform. OAuth, scheduling, publishing, PostgreSQL/BullMQ, real visual-frame evaluation, and trend ingestion are intentionally **not implemented** in this demo. No background publishing or API calls occur unless you explicitly run the application.

## Requirements

- Ubuntu 24.04 or compatible Linux, Node.js 20+ (Node 22 recommended), npm
- `ffmpeg`, `ffprobe`, `espeak` installed for free/demo narration and fallback rendering
- Chromium for Remotion rendering. On Ubuntu: `sudo apt update && sudo apt install -y ffmpeg espeak chromium-browser` (on some distributions the package is `chromium` instead of `chromium-browser`)
- Internet for one-time `npm install` and any paid API calls
- 8 GB RAM recommended; more if rendering 1080p in Chromium

## Quick start — completely local demo

```bash
unzip ReelForge-2.0-Complete.zip
cd ReelForge-2.0-Complete
cp .env.example .env
npm install
npm run dev
```

Open **http://127.0.0.1:5173**. Set a topic and click **Generate Reel**. Allow the local video process to complete; download the MP4 from the Reel Library.

`.env` defaults to `DEMO_MODE=true`. This mode makes six original gradient/illustration placeholder scenes with Sharp, creates local narration with `espeak`, evaluates a simulated storyboard and renders with Remotion (if installed/runnable) or FFmpeg. It does **not** call Claude, Gemini or ElevenLabs. Placeholder art is intentionally not claimed to be generated by Gemini.

Test prerequisites:

```bash
node -v
ffmpeg -version
ffprobe -version
espeak --version
npm run check
```

For cinematic mode only, if Remotion cannot run on your machine, set `USE_REMOTION=false` in `.env`; the fallback produces a valid H.264 MP4 from the six stills but **does not implement the animated captions, motion or layouts of the Remotion composition**. Set `USE_REMOTION=true` for the intended presentation.

## Live mode — paid API calls

1. Set `DEMO_MODE=false` in `.env`.
2. Fill `OPENROUTER_API_KEY`, and either `ELEVENLABS_API_KEY` plus an accessible `ELEVENLABS_VOICE_ID` or configure an already-running Kokoro TTS service. OpenRouter powers both text and image calls.
3. Confirm your accounts support the configured model IDs in `.env`. Provider access and prices may change.
4. Run `npm run dev`, select a topic and click Generate.

The real pipeline calls:

1. Claude Haiku 4.5 for idea and hook.
2. Claude Sonnet 4.5 for an original, six-scene storyboard.
3. Claude Haiku 4.5 for **storyboard-only** evaluation, plus Claude Sonnet 4.5 for targeted script/image-prompt revision (max three passes).
4. OpenRouter image API using `OPENROUTER_IMAGE_MODEL` (with `OPENROUTER_IMAGE_FALLBACK`) to generate **two images by default in motion-graphics mode**, or six images in cinematic mode. The fallback is tried only on API failure; it is not a scoring-based automatic upgrade.
5. ElevenLabs `eleven_flash_v2_5` for a single narration track.
6. Optional OpenRouter image-to-video clips (at most two selected scenes with `MOTION_ENABLED=true`), followed by Remotion for animated images, video clips, titles/subtitles, and FFmpeg for encoding/validation.

**Important limitations:** The evaluation is of the storyboard text, not the finished audio/video frames; it is a heuristic creative score, not a prediction of viral reach. Subtitles are **scene-timed overlays**, not word-level aligned; faster-whisper is optional (`ENABLE_WHISPER=true` after installing `services/requirements-optional.txt`); it exports word timestamps and SRT, but Remotion currently displays scene-timed overlays rather than consuming those word timestamps. Kokoro is implemented as an optional HTTP fallback for an already-running Kokoro-compatible `/v1/audio/speech` service. Live mode first attempts ElevenLabs when credentials exist, then Kokoro; demo mode uses `espeak`. Model-generated narration may not fit the fixed 30-second timing precisely; adjust your narration or use an alignment stage before deploying this pipeline. Provider costs will apply in live mode.

## Working output

Every request creates `storage/reel-<timestamp>-<suffix>/` containing:
- `job.json` — status, progress, evaluation, versions
- `storyboard.json` — six-scene structured plan
- `scene-0.png` ... `scene-5.png` — visual assets
- `narration.mp3` — audio output
- `reel.mp4` — exported short-form video

## Security / production notes

This app binds its API to `127.0.0.1` and is designed for a **single trusted local user**. It has no account authentication, per-user authorization, cloud storage, or public deployment protections. Do **not** expose port 8787 to the internet without authentication, API rate limiting, access control, secure media delivery, and queue/worker isolation. Do not commit `.env`.

Publishing to Instagram, Facebook and YouTube is **not included**. This demo deliberately isolates the core generative workflow requested for testing. Do not put social account tokens here.

This package was authored and syntax-checked in an environment without npm-registry access. Dependencies are pinned/declared but **not installed or fully integration-tested in this delivery environment**. If the SDK or model API changes, adjust the relevant provider adapter; the rest of the app remains decoupled.

## Optional Kokoro and faster-whisper

For Kokoro, start a Kokoro-FastAPI-compatible server and set `KOKORO_API_BASE=http://localhost:8880/v1`. On `DEMO_MODE=false`, ElevenLabs is tried first if credentials exist; if unavailable, the pipeline requests `POST /audio/speech` from Kokoro. Kokoro is **not bundled**; it must be installed separately with the model weights.

For timestamp export:

```bash
python3 -m pip install -r services/requirements-optional.txt
# in .env: ENABLE_WHISPER=true
```

The output includes `word-captions.json` and `subtitles.srt` on success. Caption overlays in the MP4 remain scene timed; this adapter is groundwork for a later word-accurate Remotion template.

## OpenRouter for Claude (recommended for OpenRouter subscribers)

The app automatically uses OpenRouter if `OPENROUTER_API_KEY` is set; otherwise it uses Anthropic directly. OpenRouter uses an OpenAI-compatible Chat Completions request, which is different from Anthropic's Messages API.

```env
DEMO_MODE=false
OPENROUTER_API_KEY=sk-or-v1-your-key-here
ANTHROPIC_API_KEY=
CLAUDE_IDEA_MODEL=anthropic/claude-haiku-4.5
CLAUDE_SCRIPT_MODEL=anthropic/claude-sonnet-4.5
CLAUDE_EVALUATOR_MODEL=anthropic/claude-haiku-4.5
CLAUDE_OPTIMIZER_MODEL=anthropic/claude-sonnet-4.5
OPENROUTER_IMAGE_MODEL=google/gemini-3.1-flash-image
OPENROUTER_IMAGE_FALLBACK=google/gemini-3.1-flash-image-preview
ELEVENLABS_API_KEY=your-elevenlabs-key
ELEVENLABS_VOICE_ID=your-voice-id
```

Run `npm run dev` and check `curl http://127.0.0.1:8787/api/health`. A live OpenRouter setup shows `"mode":"live"`, `"text_provider":"openrouter"`, and `"openrouter":true`. Key presence does not guarantee valid credit balance, provider availability, or successful requests. Test the first request and watch the backend logs. OpenRouter Claude models are generally billed usage-based, and require credit. The OpenRouter key is used for text and images and, when enabled, AI motion. ElevenLabs remains a separate service; Kokoro is an optional local alternative.


## Hybrid-motion upgrade (included in this complete ZIP)

This is the **complete project**, not a patch. It already contains `apps/api/src/motion.js`, video-enabled Remotion compositions, the updated storyboard pacing (3, 4, 5, 6, 6, 6 seconds), and a motion-adapter test.

- Start with `MOTION_ENABLED=false`; verify a still-image Reel first.
- Set `MOTION_ENABLED=true` to request up to two billable image-to-video clips through OpenRouter using the chosen model.
- `MOTION_SCENE_INDICES=1,3` selects the second and fourth scenes (zero-based).
- Some providers reject base64 first-frame images. If so, use a supported public HTTPS media URL.
- AI motion failures fall back to still images unless `MOTION_ALLOW_STILL_FALLBACK=false`.
- If Remotion fails and the application switches to FFmpeg fallback, that fallback renders **stills only**, not the generated motion clips or Remotion captions.
- The post-render visual evaluator and trend ingestion are not implemented. The quality scoring is currently storyboard-only.

To check the motion adapter without paid calls:

```bash
node --test tests/motion-adapter.test.mjs
```

### Important for an existing installation

The ZIP does **not** contain `.env`, API credentials, `storage/`, or existing generated videos. Keep your original installation untouched as a backup. If migrating into this folder, copy only your private `.env` and, optionally, existing `storage/` from your original project. Do not publish either directory.


## Image source selection (PropShort upgrade)

The AI Studio now supports **AI-generated images** or **Upload my images**. Uploaded assets accept JPEG, PNG, or WebP up to 20 MB per file, resize/crop to 1080 × 1920 on the API server, and are applied to video scenes in order (repeated if fewer than six are provided). The application still generates scripts and narration; uploading images skips image-generation API charges. This demo is for personal, locally bound use, not a public multi-tenant upload service.

The six reference JSON storyboards in the accompanying ZIP are examples; importing complete JSON storyboards as an executable project is not implemented in this patch.

## ReelForge 3.2 — Asset cache and selective regeneration

This complete project now includes a **Testing / Fresh Generation** choice in the AI Studio and asset cache controls in the Reel Library. Select a previously generated project and use **Render Selected Reel** to test edits with no new Claude, OpenRouter or ElevenLabs API calls. Each successful render is preserved as a numbered MP4 version. For full instructions, read [docs/CACHE-AND-REGENERATION.md](docs/CACHE-AND-REGENERATION.md).

**Cost protection:** Changing subtitles or renderer style never requires the image/voice models. Changes to narration or image prompts are shown as stale and require explicit regeneration; paid operations ask for confirmation. Every new project created under Fresh Generation still generates fresh content rather than silently recycling old scripts.

## PropShort branded graphics (3.3 update)

Set `RENDER_THEME=propshort` for the default on new projects, or change the theme of any saved project under **Asset cache & versions → Render theme**, then click **Render Again**. No new AI calls are made during this re-render. See [PropShort theme guide](docs/PROPSHORT-THEME.md) and the example JSON in `examples/propshort-ad-storyboard.json`.

## Creative Direction (ReelForge 3.4)

In a completed video's **Asset cache & versions** panel select **PropShort**, then choose **Editorial**, **Energetic**, **Cinematic** or **App Showcase**. Adjust animation intensity and entrance transition, then click **Render Again**. This reuses your cached media assets. See `docs/CREATIVE-DIRECTION.md` for per-scene JSON overrides and testing instructions.
